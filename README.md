# GreenLab 2 — инженерная приёмка контроллера теплицы

Учебная работа по дисциплине «Обеспечение качества функционирования компьютерных систем».
Группы МИП-3 / МИП-4. Версия требований: **2.0**.

## Что в репозитории

| Файл | Назначение |
|---|---|
| `report.txt` | Инженерный отчёт по ШАБЛОН_ОТЧЕТА.txt + разделы задания |
| `tests-before.json` | Набор тестов до исправления кандидата |
| `protocol-before.txt` | Протокол прогона до исправления (генерируется стендом) |
| `tests-final.json` | Итоговый полный набор (24/24, M1–M8) |
| `protocol-final.txt` | Протокол итогового прогона (генерируется стендом) |
| `candidate-before.js` | Исходная сборка поставщика |
| `candidate-fixed.js` | Исправленная сборка (3 точечные правки) |
| `change-impact.txt` | Анализ изменения требований 2.1 |
| `delta-tests.json` | Минимальные различающие сценарии для 2.1 |

## Как воспроизвести

1. Распаковать архив лабораторной работы, открыть `START.html` в браузере.
2. Импортировать `tests-before.json` → «Проверить набор» → сохранить протокол кнопкой «Скачать отчёт TXT».
3. Заменить `assets/candidate.js` на `candidate-fixed.js`, обновить страницу.
4. Импортировать `tests-final.json` → «Проверить набор» → сохранить протокол.
